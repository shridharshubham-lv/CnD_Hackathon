# Campaign Intelligence Platform

A multi-agent AI system for marketing campaign management built with **FastAPI**, **Streamlit**, **OpenAI**, **Qdrant**, **PostgreSQL**, and **Redis**.

## Architecture

The platform runs 5 AI agents in a pipeline:

| Agent | Role | Description |
|-------|------|-------------|
| Agent 1 | Brief Analyzer | Parses raw briefs, identifies gaps, generates clarifying questions |
| Agent 2 | Execution Planner | Produces structured execution plans per channel |
| Agent 3 | Consistency Checker | Compares channel assets against the brief using embeddings + LLM |
| Agent 4 | QA & Fix Agent | Ranks errors by severity, generates specific fix suggestions |
| Agent 5 | Memory Agent | Extracts reusable patterns, stores in Qdrant, warns on future briefs |

## Prerequisites

- Python 3.11+
- PostgreSQL running on `localhost:5432` (user=hackuser, pass=hackpass, db=hackdb)
- Qdrant running on `localhost:6333`
- Redis running on `localhost:6379`
- OpenAI API key configured in `backend/.env`

## Setup

### 1. Configure OpenAI

Edit `backend/.env` with your OpenAI credentials using strict `KEY=VALUE` syntax:

```env
OPENAI_API_KEY=your-openai-api-key
OPENAI_CHAT_MODEL=gpt-4o
OPENAI_EMBEDDINGS_MODEL=text-embedding-3-small
```

### 2. Install Dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 3. Start Backend

```bash
cd backend
uvicorn main:app --reload --port 8000
```

### 4. Start Frontend

```bash
cd frontend
streamlit run app.py --server.port 8501
```

### 5. Verify

- Backend health: http://localhost:8000/api/health
- Frontend: http://localhost:8501

## Usage

1. **Stage 1 — Brief Intake:** Paste a campaign brief or load a sample. Agent 1 analyzes it.
2. **Stage 2 — Clarify:** Answer clarifying questions generated by Agent 1.
3. **Stage 3 — Execution Plan:** Review the structured execution plan from Agent 2.
4. **Stage 4 — Asset Upload:** Paste channel copy assets. Agents 3 & 4 check consistency.
5. **Stage 5 — QA Report:** Review issues ranked by severity. Apply fixes or dismiss.
6. **Stage 6 — Memory & Export:** View learned patterns. Export full report as JSON or text.
